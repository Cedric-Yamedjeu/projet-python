# Projets de Formation Python

Ce dépôt rassemble les travaux et projets pratiques réalisés dans le cadre de ma formation en Python, dont certains ont été menés au cours de mon cursus académique.

## Contenu du dépôt
- **Analyse de données :** Scripts de manipulation de données avec SQlite et Json.
- **Cartographie :** Visualisation de réseaux hydrographiques et de cartes mondiales (GeoPandas, Plotly).
- **Projets divers :** Exercices et scripts d'entraînement.

## Technologies utilisées
- Python 3.14
- SQlite, GeoPandas, Plotly, Django, PyCharm
